脚本没有运行 —— 当前打开方式不执行 JavaScript

本 App 的全部内容、计算与记录都由 JavaScript 生成，脚本不执行就没有界面。**文件本身没有问题**（安卓手机、电脑浏览器都能正常打开并长期使用）。

iOS 的「文件」App 直接点开走的是"快速查看"预览，它不执行 JavaScript，所以会看到这一页；系统共享菜单里通常也不会出现 Safari。

可行的打开方式：

1. 在电脑上打开（最省事）：传到电脑双击用 Chrome / Edge 打开即可使用；数据用「我的→导出 JSON」在设备间搬移。

2. 用带内置浏览器的文件管理 App：例如「Documents」（Readdle，免费），把本文件放进去，用它的浏览器打开（能正常执行脚本）。

3. 安卓手机：用 Chrome 或任意文件管理器打开，功能完整、可离线长期使用。

4. 如果确实需要在 iPhone 上日常使用，可让开发者把 App 改造成网址形式（需联网打开；本地方式仍可离线用）。

如果你是从微信/QQ 里点开的：先「用其他应用打开」→ 存到「文件」，再参考上面的办法。
